# VoyageAI

A stateful multi-agent AI travel planning platform.

## Tech Stack

- Python
- FastAPI
- LangGraph
- LangChain
- Model Context Protocol (MCP)
- PostgreSQL
- React + TypeScript

## Planned Features

- Dynamic multi-agent orchestration
- Travel research and flight discovery
- Route and budget optimization
- Session and persistent memory
- Human-in-the-loop approval
- Itinerary versioning and rollback
- Travel document RAG
- Agent evaluation and tracing
